# Лабораторна робота 6 — сопрограми (варіант 1)

## Умова

Написати сопрограму, що генерує послідовність випадкових натуральних чисел з
проміжку [1, 256] та записує їх у чергу. Сопрограма має призупинятись, коли
черга містить більше 32 значень. Логіку призупинення реалізувати в контролері
очікування. Код сопрограми не повинен знати про контролер очікування.

## Як це влаштовано

| Файл | Призначення |
|---|---|
| `src/RandomNumberProducer.*` | **сама сопрограма** `produceRandomNumbers`: генерує число, кладе в чергу, робить `co_yield` |
| `src/QueueWaitController.*` | **контролер очікування** (awaiter): `await_ready()` повертає `false`, коли в черзі > 32 значень, і тоді сопрограма призупиняється |
| `src/ProducerTask.*` | тип-обгортка сопрограми та її `promise_type`; володіє кадром сопрограми (RAII) |
| `src/RandomNumberSource.*` | генератор рівномірно розподілених чисел з [1, 256] (`std::mt19937`) |
| `src/NumberQueue.h` | тип черги (`std::queue<int>`) |
| `src/DemoConfig.*` | розбір і перевірка вхідних параметрів |
| `src/Demo.*` | демо: раунди «відновити сопрограму → показати чергу → забрати частину значень» |
| `src/main.cpp` | точка входу, вибір джерела вводу, обробка помилок |

Чому сопрограма не знає про контролер:

```cpp
ProducerTask produceRandomNumbers(NumberQueue& queue, RandomNumberSource source) {
    while (true) {
        const int number = source.next();
        queue.push(number);
        co_yield number;
    }
}
```

Компілятор перетворює `co_yield number` на `co_await promise.yield_value(number)`.
`promise_type::yield_value` повертає контролер, який основна програма приєднала до
задачі через `ProducerTask::attach`. Отже, рішення «призупинитися чи ні» приймає
лише `QueueWaitController::await_ready()`, а в коді сопрограми немає ні контролера,
ні порогу 32.

Хід демонстрації: сопрограма стартує призупиненою (`initial_suspend`). У кожному
раунді основна програма відновлює її; сопрограма записує числа, доки в черзі не
стане 33 (тобто більше 32), і контролер її призупиняє. Потім «споживач» забирає
задану кількість значень, і раунд повторюється.

## Формат вхідних даних

Параметри — 2 або 3 цілі числа, розділені пробілами або переведенням рядка:

```
<раунди> <забирати_за_раунд> [seed]
```

| Параметр | Допустимі значення | Зміст |
|---|---|---|
| `раунди` | 1..100 | скільки разів основна програма відновлює сопрограму |
| `забирати_за_раунд` | 1..33 | скільки значень споживач забирає з черги після кожного призупинення (33 — уся черга) |
| `seed` | 0..4294967295, необов'язковий | зерно генератора; без нього береться випадкове (`std::random_device`), а використане значення виводиться, щоб запуск можна було повторити |

У файлі все від символу `#` до кінця рядка — коментар. Файл може бути у UTF-8 з BOM
або без нього. Приклади: `input/example.txt`, `input/take_all.txt`.

Помилки, на які програма видає повідомлення і завершується з кодом 1: файл не
відкривається; забагато аргументів; менше 2 або більше 3 чисел; нечисловий чи
дробовий запис (`abc`, `5.5`); переповнення; значення поза проміжком (зокрема
від'ємні). Приклади — у `input/errors/`.

## Збирання та запуск

```
build.cmd                      — збирання MSVC (C++20, /W4 /WX) у build\lab6.exe
run.cmd                        — запуск усіх прикладів, результати в results\
build\lab6.exe input\example.txt
build\lab6.exe                 — ввести параметри з клавіатури одним рядком
```

Також можна відкрити `Lab6.sln` у Visual Studio 2026.
